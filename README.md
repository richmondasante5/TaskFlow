# TaskFlow

A full-stack task management application built with Java, Spring Boot, React, and PostgreSQL. TaskFlow helps users create, organize, assign, and track tasks through a secure and user-friendly interface.

## Features

* User registration and authentication
* JWT-based authentication and authorization
* Role-Based Access Control (RBAC)
* Task creation, assignment, and management
* Task status tracking
* Secure RESTful APIs
* PostgreSQL database integration
* Responsive React frontend

## Getting Started

### Backend

1. Clone the repository
2. Configure PostgreSQL database settings
3. Run the Spring Boot application

### Frontend

1. Navigate to the frontend directory
2. Install dependencies

```bash
npm install
```

3. Start the application

```bash
npm run dev
```
